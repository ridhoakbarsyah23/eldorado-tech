# Eldorado Tech

Eldorado Tech adalah agensi pengembangan perangkat lunak (Software House) premium yang berbasis di Purwokerto. Kami menyediakan solusi IT, Web Development, Mobile Apps, UI/UX Design, dan Cloud Infrastructure berkualitas tinggi untuk membantu transformasi digital bisnis Anda.

## 🚀 Fitur Utama

- **Modern & Cepat**: Dibangun menggunakan Next.js App Router (React) terbaru.
- **Multibahasa (i18n)**: Mendukung Bahasa Indonesia (`id`) dan English (`en`) secara penuh menggunakan `next-intl`.
- **Desain Responsif**: Antarmuka pengguna yang sangat memukau dan dioptimalkan untuk Desktop, Tablet, dan Mobile (Tailwind CSS).
- **Animasi Mulus**: Pengalaman pengguna yang interaktif dengan micro-animations dan efek transisi.
- **SEO Optimized**: Praktik terbaik SEO otomatis dengan meta tag dinamis.
- **Komponen**:
  - Hero Section
  - Layanan (Services)
  - Portofolio (Portfolio)
  - Tim (Team)
  - Kontak & Formulir
  - Widget Live Chat

## 🛠️ Teknologi yang Digunakan

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [next-intl](https://next-intl-docs.vercel.app/) (Internationalization)
- [Lucide React](https://lucide.dev/) (Ikon)

## 💻 Cara Menjalankan Secara Lokal

Pastikan Anda telah menginstal Node.js di komputer Anda.

1. **Kloning Repositori**
   ```bash
   git clone <url-repo-anda>
   cd eldorado-tech
   ```

2. **Instal Dependensi**
   ```bash
   npm install
   ```

3. **Jalankan Mode Pengembangan (Development Server)**
   ```bash
   npm run dev
   ```

4. Buka [http://localhost:3000](http://localhost:3000) di browser Anda untuk melihat hasilnya.

## 🌐 Struktur Multibahasa

Aplikasi ini menggunakan perutean berbasis *locale* (misalnya `/id` atau `/en`). 
- Secara default, aplikasi akan mengarahkan pengguna ke versi Bahasa Indonesia (`/id`).
- Pergantian bahasa dapat dilakukan melalui menu *toggle* bendera yang berada di Navbar (baik pada versi Desktop maupun Mobile).

## 📄 Skrip Tersedia

- `npm run dev`: Menjalankan server pengembangan.
- `npm run build`: Membangun aplikasi untuk produksi.
- `npm run start`: Menjalankan aplikasi hasil *build* produksi.
- `npm run lint`: Memeriksa dan menemukan masalah dalam kode (ESLint).
