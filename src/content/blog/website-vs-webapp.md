# Website vs Web App

Seringkali klien kami datang dan meminta "Website" padahal yang mereka butuhkan sebenarnya adalah "Web Application" (Aplikasi Web). Apa bedanya?

## 1. Interaktivitas
- **Website Statis:** Tujuan utamanya adalah memberikan informasi (seperti portofolio, profil perusahaan).
- **Web App:** Didesain untuk interaksi pengguna. Anda bisa login, memanipulasi data, berbelanja (e-commerce), dll.

## 2. Kompleksitas
Web App memiliki logika bisnis yang kompleks di belakangnya (*backend*), membutuhkan database, otentikasi, dan keamanan tinggi. Eldorado Tech spesialis dalam membangun Web App mutakhir menggunakan Next.js dan Node.js.
